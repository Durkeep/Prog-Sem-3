# Лабораторная 3. Бинарное дерево без рекурсии

Всё находится в `lab3.py`: решение, примеры контейнеров и 5 тестов.
Нужен Python 3.10 или новее. Используются только стандартные модули
`unittest` для тестов и `collections` для именованного кортежа.

## Запуск

Из папки репозитория:

```bash
cd "Лабораторная 3"
python lab3.py
```

Программа напечатает дерево и запустит тесты. Только тесты:

```bash
python -m unittest lab3 -v
```

## Параметры и результат

Вариант 14: корень 14, высота 4, левый потомок `2 - (x - 1)`,
правый потомок `x * 2`. Формулы применяются к значению текущего узла.

```python
gen_bin_tree()  # Все параметры из варианта.
gen_bin_tree(height=2, root=5)  # Меняем высоту и корень.
gen_bin_tree(3, 10, lambda x: x + 1, lambda x: x - 1)  # Меняем всё.
```

`lambda x: x * 2` означает: получить x и вернуть x * 2.
Аннотации оставлены у высоты, корня и результата. У формул сложные
аннотации убраны: их значения по умолчанию уже являются функциями.

Высота означает число уровней: 0 даёт None, 1 даёт только корень.
При высоте 4 дерево содержит 15 узлов. Нецелая высота вызывает TypeError,
отрицательная вызывает ValueError.

Каждый узел имеет вид:

```python
{"value": 14, "left": None, "right": None}
```

В left и right хранятся словари потомков или None, если их нет.

## Алгоритм

Функция хранит узлы текущего уровня в списке level.
Цикл создаёт для них потомков и собирает следующий уровень.
После height - 1 повторений дерево готово. Функция себя не вызывает.

## Другие контейнеры

| Контейнер | Как хранить узел | Особенности |
| --- | --- | --- |
| dict | value, left, right | Доступ по ключам, поля можно менять |
| list | [value, left, right] | Доступ по индексам, элементы можно менять |
| tuple | (value, left, right) | Доступ по индексам, элементы нельзя переприсвоить |
| collections.namedtuple | Node(value, left, right) | Доступ через node.value, поля нельзя переприсвоить |
| collections.deque | Очередь узлов | Удобна для обхода по уровням, связи дерева хранятся отдельно |

Функции to_list и to_namedtuple рекурсивно преобразуют готовое дерево.
Они не меняют исходные словари. Это дополнительные примеры контейнеров.

## Тесты

Пять тестов проверяют параметры варианта 14, пустое дерево, один корень,
свои формулы и преобразование дерева в другие контейнеры.
