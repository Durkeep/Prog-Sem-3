# Лабораторная 3. Нерекурсивное бинарное дерево

Вариант 14: корень `14`, высота `4`, левый потомок `2 - (x - 1)`,
правый потомок `x * 2`. Формулы применяются к текущему узлу.

## Запуск

Из папки репозитория:

```bash
cd "Лабораторная 3"
python lab3.py
python -m unittest -v
```

Нужен Python 3.10 или новее, сторонних библиотек нет.
`lab3.py` — функция и пример, `test_lab3.py` — тесты,
`containers.py` — преобразования готового дерева.

## Объяснение

```python
from lab3 import gen_bin_tree

tree = gen_bin_tree()
small_tree = gen_bin_tree(height=2, root=5)
custom_tree = gen_bin_tree(3, 10, lambda x: x + 1, lambda x: x - 1)
```

Каждый аргумент заменяет только соответствующий параметр по умолчанию.
Высота — число уровней: 0 даёт `None`, 1 — один корень, 4 — 15 узлов.
Отрицательная высота вызывает `ValueError`, нецелая — `TypeError`.

1. Создаём словарь корня с полями `value`, `left`, `right`.
2. Помещаем корень в список текущего уровня `level`.
3. Повторяем цикл `height - 1` раз: первый уровень уже есть.
4. Для каждого узла создаём двух потомков по заданным формулам.
5. Добавляем потомков в `next_level` и делаем его текущим уровнем.
6. Возвращаем корень: через его поля доступны все созданные узлы.

`level` хранит ссылки на те же словари, которые входят в дерево.
Поэтому изменение `node["left"]` добавляет ветвь прямо в результат.
`gen_bin_tree` себя не вызывает.

Например, `gen_bin_tree(height=2)` возвращает:

```python
{
    "value": 14,
    "left": {"value": -11, "left": None, "right": None},
    "right": {"value": 28, "left": None, "right": None},
}
```

`lambda x: x * 2` — короткая функция вычисления потомка.
`Callable[[int | float], int | float]` описывает функцию из числа в число.
`dict | None` означает словарь или пустое дерево. Аннотации описывают типы;
проверка высоты написана отдельно в теле функции.

## Другие контейнеры

В `containers.py` есть `to_list(tree)` и `to_namedtuple(tree)`.
Они преобразуют готовое дерево во вложенные списки и именованные кортежи.
Эти вспомогательные преобразования используют рекурсию; основная функция
построения `gen_bin_tree` полностью нерекурсивна.

| Контейнер | Особенности |
| --- | --- |
| `dict` | Именованные изменяемые поля, основной формат по условию |
| `list` | Узел `[value, left, right]`, нужно помнить индексы |
| `tuple` | Узел `(value, left, right)`, элементы нельзя переприсвоить |
| `collections.namedtuple` | Доступ через `node.value`, `node.left`, `node.right`; поля нельзя переприсвоить |
| `collections.deque` | Подходит для очереди обхода по уровням; связи между узлами хранятся отдельно |

В построении используем списки уровней: добавляем в конец и перебираем
циклом, поэтому очередь `deque` здесь не нужна.

## Тесты и затраты

13 тестов проверяют значения варианта и число уровней, свои формулы,
частичную замену параметров, нулевой корень, дробные значения, пустое
дерево, ошибки высоты, преобразования и отсутствие вычислений потомков листа.

В полном дереве высоты `h` находится `2**h - 1` узлов. При постоянной
стоимости формул время и память для результата — `O(2**h)`.
Списки уровней требуют дополнительно `O(2**h)` ссылок.
Предела глубины рекурсии у построения нет, но большие высоты требуют много памяти.
