# Лабораторная 2. Рекурсивное бинарное дерево

Вариант 14: корень `14`, высота `4`, левый потомок `2 - (x - 1)`,
правый потомок `x * 2`. Здесь `x` — значение текущего узла.

## Запуск

Из папки репозитория:

```bash
cd "Лабораторная 2"
python lab2.py
python -m unittest -v
```

Нужен Python 3.10 или новее, сторонних библиотек нет.
`lab2.py` — функция и пример, `test_lab2.py` — тесты,
`containers.py` — преобразования в другие контейнеры.

## Объяснение

```python
from lab2 import gen_bin_tree

tree = gen_bin_tree()
small_tree = gen_bin_tree(height=2, root=5)
custom_tree = gen_bin_tree(3, 10, lambda x: x + 1, lambda x: x - 1)
```

Каждый аргумент заменяет только соответствующий параметр по умолчанию.
Высота — число уровней: 0 даёт `None`, 1 — один корень, 4 — 15 узлов.
Отрицательная высота вызывает `ValueError`, нецелая — `TypeError`.

Функция создаёт словарь текущего узла с ключами `value`, `left`, `right`.
Если высота больше 1, она вызывает сама себя дважды: для левой и правой
ветви. В каждый вызов передаются высота на единицу меньше, вычисленное
значение потомка и обе исходные формулы. При высоте 1 потомки остаются
`None`, и рекурсия заканчивается.

Например, `gen_bin_tree(height=2)` возвращает:

```python
{
    "value": 14,
    "left": {"value": -11, "left": None, "right": None},
    "right": {"value": 28, "left": None, "right": None},
}
```

`lambda x: x * 2` — короткая функция: получает `x`, возвращает `x * 2`.
`Callable[[int | float], int | float]` — аннотация функции, принимающей
число и возвращающей число. `dict | None` — словарь или пустое дерево.
Аннотации описывают типы; проверка высоты написана отдельно в теле функции.

`if __name__ == "__main__"` запускает пример только при запуске файла,
поэтому импорт в тестах ничего не печатает. `pprint` красиво выводит словарь.

## Другие контейнеры

```python
from containers import to_list, to_namedtuple

as_list = to_list(tree)
as_node = to_namedtuple(tree)
print(as_node.value)
```

| Контейнер | Представление узла | Особенности |
| --- | --- | --- |
| `dict` | `{"value": x, "left": ..., "right": ...}` | Понятные имена, можно менять поля |
| `list` | `[x, left, right]` | Можно менять элементы, нужно помнить индексы |
| `tuple` | `(x, left, right)` | Нельзя переприсваивать элементы, нужны индексы |
| `collections.namedtuple` | `Node(x, left, right)` | Доступ через `node.value`, поля нельзя переприсвоить |
| `collections.deque` | Очередь узлов | Удобна для обхода по уровням через `append` и `popleft`; связи дерева хранятся отдельно |

В `containers.py` реализованы рекурсивные преобразования в список и
именованный кортеж. Они сохраняют обе ветви и не меняют исходное дерево.

## Тесты и затраты

13 тестов проверяют значения варианта и число уровней, свои формулы,
частичную замену параметров, нулевой корень, дробные значения, пустое
дерево, ошибки высоты, преобразования и отсутствие вычислений потомков листа.

Полное дерево высоты `h` содержит `2**h - 1` узлов. При постоянной стоимости
формул время и память для результата — `O(2**h)`, глубина рекурсии — `O(h)`.
Большая высота требует много памяти и может превысить предел рекурсии Python.
